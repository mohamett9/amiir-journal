# Amiir Journal

Joornaal ganacsi (trading journal) — Journal, Dashboard (performance calendar), iyo Checklist (CRT / MMXM).

No login — each visitor's data is stored in their own browser via `localStorage`.

## Run locally

```bash
npm install
npm run dev
```

Fur http://localhost:5173

## Deploy

Push to GitHub, then import the repo into [Vercel](https://vercel.com) or [Netlify](https://netlify.com) (both free) for a public link.
